## About

I am an XR software engineer and Ph.D. student in Computer Science at the University of Missouri, with **5+ years of Unity and C# experience** designing, building and shipping AR, VR and MR applications, live mobile games and multiplayer games.

My current work is real-time XR systems that bring AI into live headset sessions, and research on how to make them secure, private and comfortable for the people using them. That work has led to **9 peer-reviewed papers** and an **IEEE ISMAR 2025 Best Poster Award**.

- Real-time XR pipelines that stream headset camera, eye-tracking and sensor data to AI models
- Unity AR, VR and MR apps for Meta Quest, Microsoft HoloLens, Magic Leap and HTC Vive
- Player-facing features for a live mobile title, VR sports games, browser and mobile games
- Controlled user studies and machine-learning methods for safer, more comfortable XR

## About this site

A single-page portfolio written by hand: semantic HTML, one CSS file and a small JavaScript file, with scroll animation from [GSAP](https://gsap.com/) and ScrollTrigger (loaded from a CDN with integrity hashes). It is served by GitHub Pages from the `Portfolio_` branch. Visits are counted with StatCounter.

```
index.html              the whole page
assets/css/styles.css   styles
assets/js/main.js       motion, navigation, video pop-up
assets/img/             project images
istiak-ahmed-cv.pdf     current CV
```

To view it locally: `python -m http.server 8000`, then open http://localhost:8000.
